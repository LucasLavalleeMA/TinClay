# Changelog

## 1.1.1

### Added

- Home screen with blank and kinetic energy templates, recent and pinned files,
  missing-file recovery, and prompts for unsaved changes.
- Windows `.clay` file association and opening a workspace from the command line.
- Slate, Rose, and Teal table-style presets for selected ranges.
- Save As and keyboard shortcuts for Save, Save As, and Open.
- Symbol editing beside the unit control in the Variable ribbon group.

### Changed

- Updated the application and Home icons.
- Improved variable dragging and its preview while scrolling.

## 1.1.0

- Initial public Windows release of TinClay.
